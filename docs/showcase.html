什么结构Architecture
三层：SKILL.md（触发与规则）→ references/tokens.md（色卡变量 / 字体阶梯 / 间距）→ assets/base.css + templates/*.html（零依赖骨架）。换肤 = 变量覆盖，不改结构。Three layers: SKILL.md (trigger & rules) → references/tokens.md (variables / type scale / spacing) → assets/base.css + templates/*.html (zero-dependency skeletons). Reskin = variable override, structure untouched.
