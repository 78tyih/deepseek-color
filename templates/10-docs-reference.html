快速开始

五分钟接入 Aurora：创建一个组合，贴上持仓，让模型给出第一份风险简报。本文覆盖 API Key 申请、首次调用与结果解读。

1. 获取 API Key

控制台 → 开发者设置 → 新建 Key。Key 仅在创建时完整展示一次，请妥善保存。所有请求通过 Authorization: Bearer 头鉴权。

2. 创建第一个组合

# 创建组合并上传持仓 curl -X POST https://api.aurora.example/v2/portfolios \ -H "Authorization: Bearer $AURORA_KEY" \ -d '{"name":"核心仓位","holdings":[{"symbol":"600519","weight":0.18}]}'

3. 请求风险简报

curl https://api.aurora.example/v2/portfolios/{id}/brief # → { "summary": "...", "risks": [...], "sources": [...] }
简报中的每一条结论都带 sources 溯源字段，审计场景请保留原始响应。
